🎓 Student Registration & Result Portal

A simple and responsive Student Registration & Result Portal built using HTML, CSS, and JavaScript. The application allows students to enter their personal details, select a course, record their information, and view their result through an easy-to-use interface.

✨ Features
📝 Student registration form
👤 Full Name and Roll Number fields
📧 Email validation
📱 10-digit phone number validation
🎂 Date of Birth selection
🎓 Course selection dropdown
✅ Form validation
📊 Submit & View Result functionality
🔄 Reset Form option
📱 Clean and responsive design
🎨 Modern student-friendly UI

🛠️ Technologies Used
HTML5 – Structure
CSS3 – Styling and responsive layout
JavaScript – Form validation and result functionality
